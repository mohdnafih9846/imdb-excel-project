IMDb Movies Data Analysis Dashboard

📌 Project Overview

This project is an IMDb Movies Data Analysis Dashboard created using Microsoft Excel and Power Query.

The project focuses on cleaning movie data, analyzing important movie metrics, and presenting the results through PivotTables, PivotCharts, and an interactive Excel dashboard.

📂 Dataset

The dataset was collected from Kaggle:

🔗 Kaggle Dataset:
https://www.kaggle.com/datasets/hetbabariya/imdb-movies-data-collection-5000-records

🧹 Data Cleaning

Power Query was used to clean and prepare the raw movie data.

Main cleaning steps included:

Removing blank rows

Trimming unnecessary spaces

Checking and changing data types

Handling missing values

Cleaning text fields

Preparing Budget and Gross values

Converting large values into readable Million/Billion formats

🎯 Project Objective

The objective of this project is to transform raw IMDb movie data into a clean and understandable dataset and create a dashboard that helps summarize movie performance across different genres, countries, companies, years, and actors.
